## This is us ── 私たちについて

<img width="1091" height="409" alt="image" src="https://github.com/user-attachments/assets/10cfc249-ff0b-4079-aded-acabb35ad09a" />


京都・西陣の地で、私たちは **1946年（昭和21年）** から印刷とともに歩んできました。

活版からオフセット、そしてデジタルへ。時代とともに技術は移り変わりましたが、創業以来ただ一つ、変わらないものがあります。それは **「お客様の想いを、かたちにする」** という姿勢です。

私たちが大切にしているのは **不易流行** ── 変えるべきものは果敢に変え、変えてはならないものは守り抜く。新しい技術にはチャレンジ精神をもって挑み、お客様に寄り添う心は創業の日のまま。その両立こそが、長く選ばれ続けてきた理由だと考えています。

だからこそ私たちは、自らを「印刷会社」の枠に閉じ込めません。「刷る」だけの会社から、「創る」会社へ。紙の上の仕事を起点に、人と人、想いと想いをつなぎ、まだ世にない「新しいコト」を生み出していく ── それが、これからの山代印刷です。

> お客様の想いをかたちにすること、これこそが、私たちの喜びです。

## 私たちの物語

戦前、紙管をつくる小さな商店として始まった私たちは、戦後の復興とともに印刷業へと踏み出しました。

昭和47年、工場が全焼するという危機に見舞われます。それでも私たちは立ち止まりませんでした。**わずか半年で復興** を遂げ、お客様への約束を守り抜いたのです。

「難しいケースでも、簡単には諦めない」── この一節は、単なる標語ではありません。火の中から立ち上がった私たちが受け継いできた姿勢そのものです。

## 私たちにできること

「印刷」という言葉だけでは語りきれない、トータルなクリエイティブ・サポートを提供します。

| サービス | 私たちが届ける価値 |
|---|---|
| **企画・デザイン** | デザイナー・イラストレーター・ライター・写真家・映像作家のネットワークで、「刷る」前の「創る」段階からご一緒します。 |
| **印刷** | 学会誌・記念誌・会員名簿・ポスター・パンフレットから美術印刷まで。オンデマンドの少部数から大量印刷まで、仕分け・発送までワンストップ。 |
| **Web開発** | コーポレートサイト・特設サイト・EC構築。紙とWebを連動させた提案が私たちの得意分野です。 |
| **出版** | 出版部を擁するISBN登録出版者。学術専門書を自社一貫で低コストに。詳しくは下記の出版部の節を。 |
| **その他** | 学会運営事務代行・イベント運営・社内IT化コンサルティング・マーケティング・翻訳まで。 |

## 選ばれる理由

- **型通りで終わらせない。** お客様の声に耳を傾け、ご要望に即して企画・デザイン段階からご提案します。
- **「あらゆる印刷」に応える総合力。** 微細さ・鮮明さが求められる美術印刷から、学術書の編集・出版まで。
- **印刷の外側まで届くネットワーク。** 写真・動画・電子書籍化・Web構築・イベント運営・マーケティング戦略まで。
- **諦めない姿勢。** 限られたご予算の中で、タイトな納期で、他社が断る案件でも ── 最大限の努力で「実現」を目指します。

## 山代印刷 出版部 ── 本を出すための、新しい選択肢

> 京都での出版なら、山代印刷出版部。

「既存の出版社では扱ってもらえない専門書を出したい」「でも、著者の費用負担が重すぎる」── そんな声に応えるために、私たちは印刷会社としてのノウハウを活かして **出版部** を立ち上げました。印刷から出版までを自社で一貫できるからこそ実現できる、出版のかたちがあります。

| 出版部の強み | 内容 |
|---|---|
| **低コスト・高品質** | 外部への印刷外注が不要。通常印刷から美術印刷まで自社対応で、良質な一冊を無理のない費用で。 |
| **著者負担なしの出版も** | 販売部数が見込める企画なら、費用負担なしでの出版も可能。負担ありの場合も安価に。 |
| **ISBN付与・多角販売** | 出版社登録済み。ISBNを付け、自社サイト直販に加えAmazonでも販売。完売・重版の実績も。 |
| **企画段階からの編集・デザイン** | 専属の編集者・デザイナーが伴走。古文書に詳しいスタッフも在籍し、寺社・文化財の歴史書にも対応。 |

学術専門書（医学・倫理・社会・経営・歴史など）から、寺社・文化財資料、同人誌・詩集・句集・歌集の自費出版まで。著者の想いに寄り添いながら、出版契約をきちんと交わし、トラブルなく一冊をかたちにします。

[**出版部について詳しく**](https://www.yamashiroprint.co.jp/publication_lp/)
